# ROB RUN Wiki v0.1-demo

Первая демо-версия вики предметов.

- 11 разделов с реальным количеством предметов из базы: 321 предмет из 506 попадает в вики.
- 10 заполненных страниц: RC 5.56 Mk3, патроны для штурмовой винтовки, штурмовой бронежилет, инъектор, дымовая граната, мини-бур, USB-взломщик, ключ-карта галереи, плантация, счётчик банкнот.
- Страница предмета: характеристики, как получить, где используется, экономика.
- Проект из отдельных файлов: разметка, стили, скрипт, данные, картинки и скрипт сборки данных из атласа.

Запуск: откройте index.html в браузере или выполните `npm start` (Node.js 22+) и откройте http://localhost:3000.
