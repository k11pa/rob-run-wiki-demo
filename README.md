# ROB RUN Wiki · демо

Пример вики предметов ROB RUN: 11 разделов и 10 заполненных предметов.

Откройте index.html в браузере. Это одна страница, картинки встроены в неё.

В вики попадают предметы, у которых есть применение или другой способ получения: покупка, бартер, заполнение, база. Предметы «только для продажи», которые просто лежат в открытом мире, исключены. По базе robrun_wiki (сборка 26342425) это 321 предмет из 506.

На странице предмета: характеристики, как получить, где используется, экономика (базовая цена и продажа скупщику на уровнях 1–5).
