# ROB RUN Wiki · demo 0.1

Вики предметов ROB RUN. Демо-версия: 11 разделов и 10 заполненных страниц предметов. Оформление в стиле интерфейса игры, как у атласа лута.

## Запуск

Откройте `index.html` в браузере. Сервер не нужен: данные лежат в `data/items.js`, картинки в `assets/items/`.

С локальным сервером (Node.js 22+):

    npm start

Затем откройте http://localhost:3000.

## Какие предметы попадают в вики

Предметы, у которых есть применение или способ получения кроме находки в мире: покупка, бартер, заполнение, двери, сейфы, база. Предметы «только для продажи», которые просто лежат в открытом мире, исключены. По базе robrun_wiki (сборка 26342425) это 321 предмет из 506.

## Разделы

Оружие · Боеприпасы · Броня и снаряжение · Медицина · Гранаты · Инструменты и прочее · Ключи и доступ · Бартер и заполняемые предметы · База: постройки и мебель · Улучшения базы и авто · Рейд.

## Страница предмета

- Шапка: картинка, редкость, раздел, описание из игры, тип, размер в инвентаре, размер стопки.
- Характеристики: у оружия урон, урон в голову, скорострельность, магазин, дальность полного урона, перезарядка, прицеливание, доставание, режим огня и патроны; у брони число сегментов.
- Как получить: торговцы и цены, стоимость открытия в дереве торговли, заполнение.
- Где используется: подходящее оружие для патронов, двери для ключей, сейфы для мини-бура, рецепты бартера.
- Экономика: базовая цена и продажа скупщику на уровнях 1–5.

## Структура

    index.html            разметка страницы
    css/style.css         стили
    js/app.js             разделы, список и страница предмета
    data/items.js         данные (генерируются, руками не править)
    assets/items/         картинки предметов
    scripts/build-data.js сборка данных из проекта rob-run-atlas
    scripts/serve.mjs     локальный сервер

## Обновление данных

Данные берутся из сгенерированных файлов атласа (`dist/data.js`, `dist/db.js`), которые собираются из базы robrun_wiki в Supabase. Положите рядом проект `rob-run-atlas`, выполните в нём `npm run build`, затем здесь:

    npm run build:data

Список предметов с полной страницей задаётся в `scripts/build-data.js` (константа `SAMPLE`).

## Чего пока нет в базе

Где выпадает конкретное оружие, что производит плантация, насколько ускоряет улучшение стола и параметры брони кроме числа сегментов. На страницах предметов это указано прямо.
